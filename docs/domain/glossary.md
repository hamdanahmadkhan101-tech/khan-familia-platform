# Glossary

- Availability: Remaining capacity for a unit type or tour departure.
- Booking: Confirmed reservation with payment intent captured.
- Hold: Temporary reservation of inventory pending payment.
- Inquiry: Initial customer intent captured from web, phone, or WhatsApp.
- Inventory: Sellable units (unit types or departures).
- Departure: Scheduled tour occurrence with capacity.
- Custom Tour Request: Bespoke tour inquiry requiring manual quotation.
- Quote: Negotiated offer with price snapshot and expiry.
- Rate Plan: Rules that define how prices are calculated.
- Price Snapshot: Immutable pricing result attached to a booking.
- Manual Task: Operator work required to progress a booking or inquiry.
- Vendor: Supplier that owns properties or tours.
- Unit Type: Inventory class for properties (e.g., Deluxe Room).
- Capacity: Maximum available units or seats.
- Cancellation Policy: Rules governing refunds and fees.
